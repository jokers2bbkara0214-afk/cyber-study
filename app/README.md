## 起動方法

1. ZIPを**すべて展開**してください。ZIP内から直接 `index.html` を開かないでください。
2. 展開したフォルダ内の `index.html` をChrome/Edgeで開いてください。
3. 「教科書」→ **「教材本文（15講）」** を押して、1-1「2進数って何？」を開いてください。ホーム画面下部の「教材本文を開く」からも入れます。
4. 「1つ進める」で数値を動かし、本文下部の「チェック」とアプリ上部の「学習済み」をそれぞれ試してください。
5. 学習後は「設定」→「バックアップを書き出す」でJSONファイルを保管してください。

**重要：** `file://` での iframe 読込と保存動作は、この実行環境では直接確認できていません。Chrome/Edgeで確実に同一オリジンで開くには、Pythonがある場合は展開フォルダで `python -m http.server 8000` を実行し、ブラウザで `http://localhost:8000/` を開いてください。VS CodeのLive Serverでも構いません。フォルダの場所や起動URLを変えると、localStorageの保存領域が変わる場合があります。**切替前に旧版のJSONバックアップを取ってください。**
