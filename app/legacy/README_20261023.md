# CYBER STUDY 4.0 | 2026-10-23 MAINLINE

**状態：開発途中（10月31日の6機能MVP目標）。完成版ではありません。**

## 最重要：どの版がベースか

本パッケージは **2026-10-21の「CYBER-STUDY-4.0-REFERENCE-INTEGRATED」** を基礎としたメインラインです。2026-10-22の小規模9レッスン試作版を土台にはしていません。これにより、既存の14レッスン・66カード・オリジナル1200問・SQL200ミッション・安全な仮想ハッキング等・参考画像18枚を保全しました。

2026-10-22の小規模試作版には別の改良があり、**両系統はまだ統合できていません**。本パッケージでは豊富な旧機能を優先して保持し、追加したのは出典付きIPA改題6問・7日間の学習履歴グラフ・教材照合の未完了表示です。

## 起動

1. ZIPを展開して、フォルダ内の `index.html` をChromeまたはEdgeで開きます。
2. 画面左の6つの学習機能を選択します。
3. 「応用情報技術者試験問題集」には **オリジナル1200問** と **IPA公式問題の改題6問** の切替ボタンがあります。
4. 保存先はブラウザの `localStorage` です。元の版で使っている場合、先に「設定 → バックアップを書き出す」でデータを保管してください。

## 安全性・動作環境の注意

- 仮想ターミナル/Web障害演習のコマンドは**文字列判定**です。実コマンドの実行はしません。
- SQL演習は参照系の安全制限があります。ただしSQLite高度演習は外部CDNのsql.jsに依存するため、完全オフライン動作は保証しません。
- CSSにはGoogle Fontsへの外部参照があります。未接続でもフォールバックフォントで表示できますが、書体は変わります。
- ブラウザを変えるとローカル保存領域も変わる場合があります。
